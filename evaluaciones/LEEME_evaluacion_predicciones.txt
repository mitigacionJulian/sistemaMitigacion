2. DÓNDE SACAR CADA COLUMNA DEL CSV
──────────────────────────────────────────────────────────────────────────────

  sin_modelo          → «no» si hay gráfico con ajuste; «si» si aparece aviso sin proyección
  n_meses_ajuste      → meses usados en el ajuste (sin mar–ago 2020 si excluir COVID = sí)
  r2, rmse, mape_pct  → métricas IN-SAMPLE (línea de ajuste bajo el gráfico)
  aic, bic            → solo ARIMA / SARIMA
  bondad_nivel        → caja «Interpretación del ajuste» (bueno / moderado / bajo)
  r2_holdout          → panel hold-out → R²
  rmse_holdout        → panel hold-out → RMSE
  mape_holdout_pct    → panel hold-out → MAPE  ★ MÉTRICA CLAVE
  bondad_holdout      → panel hold-out → nivel de bondad
  holdout_activo      → «si» si el panel muestra tabla mes a mes; «no» si indica motivo
  proyeccion_razonable→ su criterio visual: si / no / parcial
    Regla aplicada en A,G,H,I (coherente con métricas):
      · no: sin modelo, hold-out inactivo, o MAPE hold-out > 25 %
      · si: MAPE hold-out ≤ 20 % (y ≤ 15 % si R² muy bajo no aplica), escenario no G
      · parcial: MAPE hold-out 20–25 %; escenario G (serie 6 meses); R²≈1 en I;
        OLS/ARIMA con R² < 0,15 pero MAPE hold-out 15–20 %

──────────────────────────────────────────────────────────────────────────────
3. IN-SAMPLE vs HOLD-OUT (concepto central)
──────────────────────────────────────────────────────────────────────────────

  IN-SAMPLE (ajuste histórico)
    El modelo «ve» todos los meses del periodo y se mide qué tan bien los reproduce.
    · R² alto aquí NO garantiza buena predicción futura.
    · Puede haber sobreajuste: memoriza el pasado pero falla en meses nuevos.

  HOLD-OUT / prueba con meses reservados (validación predictiva)
    Se reservan los últimos N meses (3 o 6), se entrena SIN ellos y se predice esos meses.
    · En la UI: panel «Prueba del modelo».
    · Es la métrica principal para elegir modelo.

  Regla: para DECIDIR modelo → priorice MAPE hold-out.
         para DESCRIBIR ajuste → use R² / MAPE in-sample como complemento.

5. CONFIABILIDAD 80 % — QUÉ COEFICIENTE CITAR
──────────────────────────────────────────────────────────────────────────────

  Pregunte al profesor cuál de estas dos interpretaciones usa:

  ┌─────────────────────────────────────────────────────────────────────────┐
  │ A) «80 % de exactitud / confiabilidad predictiva»                       │
  │    Métrica: MAPE hold-out                                               │
  │    Umbral:  MAPE hold-out ≤ 20 %                                        │
  │    Lectura: Precisión estimada ≈ 100 % − MAPE                           │
  │             MAPE 15 % → precisión ≈ 85 %  ✓ cumple 80 %                  │
  │             MAPE 22 % → precisión ≈ 78 %  ✗ no cumple                   │
  └─────────────────────────────────────────────────────────────────────────┘

  ┌─────────────────────────────────────────────────────────────────────────┐
  │ B) «El modelo explica el 80 % de la variación de la serie»              │
  │    Métrica: R² (coeficiente de determinación)                           │
  │    Umbral:  R² ≥ 0,80                                                   │
  │    En accidentes mensuales con COVID, casi ningún modelo alcanza 0,80.  │
  │    El mejor in-sample en escenario A es MA con R² ≈ 0,60.               │
  └─────────────────────────────────────────────────────────────────────────┘

  Recomendación para sustentación (interpretación A):
    «El modelo se considera confiable para proyección exploratoria cuando el
    MAPE en validación hold-out es ≤ 20 %, equivalente a una precisión estimada
    del 80 % o superior, complementado con exclusión del confinamiento COVID
    del ajuste y lectura visual del gráfico.»

  Si el profesor insiste en R² ≥ 0,80:
    Documente que la serie de siniestralidad vial mensual no alcanza ese umbral
    por estacionalidad, shocks (COVID) y naturaleza de conteo; justifique el
    tablero como herramienta exploratoria con validación hold-out.
